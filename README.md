## 🗺️ How I think about Data Engineering

Tools change. The responsibilities of a good data platform don't change nearly as fast.

```text
 SOURCE          INGEST          STORE         TRANSFORM         SERVE
   │                │              │               │                │
   ▼                ▼              ▼               ▼                ▼
 APIs / DB  ──►  Pipelines  ──►  Cloud Data  ──► SQL / dbt  ──► Analytics
                                      │
                         ┌────────────┴────────────┐
                         ▼                         ▼
                    Reliability               Observability
                    Data Quality                  Cost
                    Recovery                  Performance
````

> I like the messy part of Data Engineering, legacy SQL, growing pipelines,
performance bottlenecks, unclear business logic, and systems that need to become
reliable enough for production.
